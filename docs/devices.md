# 设备分辨率对照

| 设备 | 屏幕 | 原生分辨率（横屏） | 宽高比 | 建议缩放 | 备注 |
|---|---|---|---|---|---|
| OPPO Pad 5 Pro | 13.2" LCD | 3392 × 2400 | 1.4133（≈√2，官方称 7:5） | 200% | 与 Pad 4 Pro 分辨率相同 |
| OPPO Find N6（内屏） | 8.12" AMOLED | 2480 × 2248 | 1.1032 | 200% | 近方形；竖屏为 2248 × 2480，不在本工具适配范围 |
| OPPO Find N6（外屏） | 6.62" AMOLED | 2616 × 1140 | 2.2947 | 150% | 可在 `TabletScreen.ps1` 中自行扩展 |

## 为什么必须匹配原生分辨率

远程画面是按“像素 + 宽高比”映射到接收端的。若主机输出与接收端比例不同：

- 拉伸 → 变形；
- 等比 → 黑边。

例如电脑内屏 2560×1600（1.6）投到 Pad 5 Pro（1.4133）：

```
纵向变形 = 1.6 / 1.4133 - 1 ≈ 13.2%
```

而 2560×1600 → Find N6 内屏（1.1032）：

```
1.6 / 1.1032 - 1 ≈ 45%
```

把主机分辨率设成与设备完全相同，就能实现 1:1。

## 扩展新设备

1. 在 `scripts\Watcher.ps1` 的 `Get-TargetSize` 增加匹配：

```powershell
if ($dev -like '*你的设备名*') { return @{ W = 宽; H = 高 } }
```

2. 在 `scripts\TabletScreen.ps1` 的 `$Profiles` 增加对应档位（手动模式用）。
