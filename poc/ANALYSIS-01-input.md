# 输入诊断 #1 —— OPPO Pad 5 Pro 专属键盘/触控板

测试时间：2026-11-03 01:52–02:01（远程会话中，仅用平板键鼠）

## Windows 键结论

- Win 键事件以注入方式到达（`flags=0x11`），Win+R 能真正触发系统运行对话框 → **系统层完全正常**；
- Raycast 对注入键不做响应（很多启动器的安全策略），所以“按 Win 不弹 Raycast”是 Raycast 侧行为，不是 OPPO 没传。

## 解决：Win 键桥接（poc/RaycastBridge.ps1）

检测 **远程注入的裸 Win**（按下/抬起成对、期间没按别的键），直接调用 `raycast://`：

- 裸 Win → 唤起 Raycast；再按一次 → Esc 关闭；
- Win+R / Win+D / Win+Tab 等组合不受影响（组合键有其他键按下，不触发桥接）；
- 只响应注入键，本地物理 Win 键行为不变。

自测结果：

```
02:01:36  裸Win -> 唤起 Raycast
02:01:38  裸Win -> 关闭 Raycast
```

## 触控板缺口

- 双指横向滚动、三指手势没有任何原始事件 → 平板/客户端侧消费，PC 端无法凭空补齐；
- 可选的替代方案：用可用的按键/组合（如 Alt+Tab、Win+Tab）替代手势，或后续看客户端是否提供开关。
