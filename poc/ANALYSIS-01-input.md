# 输入诊断 #1 —— OPPO Pad 5 Pro 专属键盘/触控板

测试时间：2026-11-03 01:52–01:57（远程会话中，仅用平板键鼠）
样本：2284 个原始输入事件

## 结论摘要

| 类别 | 结果 |
|---|---|
| 字母/数字/修饰键/方向键/F1/Esc/Tab/Backspace | ✅ 全部到达，键码+扫描码正常 |
| Windows 键 | ✅ 原始事件到达（`vk 0x5B`，带注入标志），Win+R / Win+D / Win+Tab 的按键序列都出现在流里 |
| 触控板指针 | ✅ 1643 个移动事件 |
| 触控板左键 | ✅ 43 次按下/释放 |
| 触控板右键 | ✅ 1 次（0x204/0x205） |
| 双指垂直滚动 | ✅ 61 个滚轮事件，±35 步长 |
| 双指水平滚动 / 横向滚轮 | ❌ 0 个 `0x20E` 事件 |
| 三指手势（上滑/左右） | ❌ 没有对应手势事件；但测试窗口内出现 **56 次 Alt 按下 + 58 次 Tab 按下**（01:55:40–01:56 密集），疑似某种手势/组合键映射或连续按键 |
| 中键 | ❌ 无 |

## 关键细节

- Win 键事件带 `flags=0x11`（LLKHF_INJECTED），说明是客户端注入而非物理键；
- Win 按下到 R 按下间隔约 456ms，Win 仍处于按下状态，因此 OS 层应能识别 Win+R；
- Win 单按的按下/释放间隔达 2 秒以上，可能是客户端对 Win 键做了特殊处理；
- 触控板滚动只发垂直滚轮（无水平），说明双指横滑/三指左右很可能被平板端消费。

## 待确认（需要你观察）

1. 单独按 Win 时，电脑的**开始菜单**有没有弹出？
2. Win+R 时，电脑有没有弹出**运行对话框**？
3. Win+D / Win+Tab 有没有效果？
4. 三指上滑/左右时，平板和电脑分别有什么反应（电脑有没有出现任务视图/切换）？

## 下一步

- 写快捷键效果检测器（窗口级验证开始菜单/运行框/任务视图是否真的出现），排除“事件到了但被系统/客户端拦截”；
- 若 Win 组合实际无效：找客户端拦截点，或做 PC 端替代映射（如 Ctrl+Esc 映射 Win、自定义组合键）；
- 触控板横向/三指：若无原始信号，则客户端未发送，PC 端无法凭空补齐，只能做替代方案。
